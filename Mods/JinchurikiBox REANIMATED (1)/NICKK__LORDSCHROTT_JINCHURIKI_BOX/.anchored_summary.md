## Key Decisions
- Drop WorldTip entirely — use TipButton approach on bars + text line in description area.
- TipButton on cloned bars needs `raycastTarget = true` because the original health bar graphics have it false, preventing OnPointerEnter detection.
- Description text modification uses two-tier search: keyword match first, then heuristic fallback.
- `data.get(string, out T)` returns void (cannot use in if-condition) — call separately then check value.
- `StatusAsset` uses `action_interval` not `interval`.
- `setAttackTarget(null)` not `setTarget(null)`.
- `World.world.units.getSimpleList()` not `AssetManager.actors.getAlive()`.
- `ActorData.remove(key)` doesn't exist — use `data.set(key, 0f)` instead.
- Tooltip callback registered lazily on first `ShowContent_Postfix` call (delay on first hover).
